# SekolahMu App

A simple Android WebView application for accessing **SMM (Sekolah Murid Merdeka)** with a cleaner, faster, and more app-like experience than using a regular browser.

> **Status:** Beta  
> **Current Version:** v2.1.0-beta

## Features

- Automatic redirect to SMM
- Double back press to exit
- Download support
- Internet connection detection
- Offline page
- Browser prompt support

### New Features

- Firebase Realtime Database integration
- Real-time server status monitoring
- Remote maintenance mode
- Custom maintenance page
- Automatic maintenance recovery without restarting the app
- Intro loading screen
- Background blur effect during intro
- Automatic content error detection
- Custom application error page
- Automatic redirect after splash screen
- GitHub Releases integration
- In-app update checker
- Version comparison system
- Force update support
- Optional update support
- Update dialog with changelog
- APK download from GitHub Releases
- Firebase-based update configuration
- Responsive splash screen page
- Improved startup flow
- Better loading experience
- Various UI improvements
- Various performance optimizations
- Various bug fixes

## Installation

1. Download the latest APK from the Releases page.
2. Install the APK on your Android device.
3. Open the application.
4. Sign in using your SMM account.
